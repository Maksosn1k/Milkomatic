# Milkomatic [![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)
Automated milk production with dispensers


## Download plugin

* [release](https://github.com/Maksosn1k/Milkomatic/releases) or [modrinth](https://modrinth.com/plugin/milkomatic)

## Config settings
```
settings:
  throw-speed: 0.5
  enable-sounds: true
  detection-radius: 1.2
```
